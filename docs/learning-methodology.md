# 学习方法论：怎么核对"真的学会了"

> 核心原则：**能认出 ≠ 能回忆，能回忆 ≠ 能复现。"学会了"的唯一可靠判据是——不看材料，能把东西重新做出来。**

本文档是这个仓库所有学习活动的执行规范。进度表里的 ✅ 只有满足这里的通过标准才能打。

---

## 一、理论基础（为什么这么学）

认知科学有大量证据支持的结论（Dunlosky 2013 元分析等）：

| 方法 | 效果 | 说明 |
| --- | --- | --- |
| 主动回忆（Active Recall） | ★★★★★ | 单一最有效技术。合上书自测，远胜重读 |
| 间隔重复（Spaced Repetition） | ★★★★★ | 1天/1周/1月后重测，对抗艾宾浩斯遗忘曲线 |
| 交错学习（Interleaving） | ★★★★ | 混合主题学比单主题猛刷更利于长期保持 |
| 费曼技巧（Feynman） | ★★★★ | 用自己的话讲给外行听，讲不清=没懂 |
| 重读、划线 | ★ | 产生"熟悉感"幻觉，基本无效 |

**能力幻觉（Illusion of Competence）**：看视频时觉得"都听懂了"，是因为材料在眼前，大脑把"认得出"误认为"想得起"。检测方法只有一个——撤走材料，看还能剩多少。

**费曼技巧的严格版**（费曼本人的做法）：卡住时不要立刻翻书，先**从已知知识尝试推导**，推完再对照原文验证。"重新推导"比"回去抄一遍"高一个层级。

## 二、五层核对标准

每学完一个单元（一讲视频 / 一章书 / 一个作业），按层级自测。**第 1-2 层通过只能算"看过"，第 4-5 层通过才算"学会"。**

| 层级 | 名称 | 检验方式 | 通过标准 |
| --- | --- | --- | --- |
| L1 | 能回忆 | 关掉材料，白纸默写要点 | 写出主干结构 + 关键术语/公式，不卡壳 |
| L2 | 能解释 | 用自己的话写清"为什么" | 能写出因果链（为什么负采样？为什么 attention 除 √d？），不是复述定义 |
| L3 | 能推导 | 关键数学/代码合上材料手推 | 反向传播、注意力矩阵维度、BPE 合并过程等能独立推出且与原文一致 |
| L4 | 能动手 | 作业/实验不看答案独立完成 | 测试全绿（CS224n a3 的 pytest、CS336 的 tests、ai-agent-book 实验能跑通） |
| L5 | 能迁移 | 1-2 周后重做核心部分，或讲给别人/AI 听 | 不需要重看课程；能回答"如果换个场景怎么改" |

**打 ✅ 的规则**：
- 视频/slides 打 ✅：至少过 L1 + L2（有白纸笔记且缺口已补）
- 作业/实验打 ✅：必须过 L4（独立、测试通过）
- 一本书/一门课标"完成"：全部单元 ✅ + 做过一次 L5 级回顾

## 三、单单元标准流程（每讲/每章 60-90 分钟）

```
① 输入（30-40min）   看视频 / 读 slides / 读书的一章
                      ↳ 不做详细笔记，只记"哪里没听懂"
② 白纸输出（15min）   关掉一切材料，在 notes/ 里默写：
                      - 这讲的骨架（讲了哪几件事，什么关系）
                      - 关键公式/机制 + 它们为什么是这样
                      - 记得的例子
③ 对照补漏（10min）   翻原文对照，漏掉/记错的用 **粗体** 或 ❌ 标出
                      ↳ 这些标记就是下次复习的唯一重点
④ 动手验证（30min+）  做作业对应部分 / 跑书里的实验（不看答案）
⑤ 归档               更新进度表 ✅，在笔记末尾写 3 行：
                      - 我卡在哪 → 为什么卡 → 下次怎么一眼想起来
```

**间隔复习节奏**：每篇笔记写完，在文件头加 `review: D+1 / D+7 / D+30` 三个日期；到点只做一件事——把 ③ 标出的缺口部分重新白纸默写一遍。全对就划掉该日期。

## 四、多路并行的安排（你当前的情况）

当前三条线：**CS224n 视频课**、**CS336**、**《深入理解 AI Agent》**。三条线内容有天然呼应，不要平均用力，按"一主两辅"组织：

### 主线轮换，不要三线同天

- **每天只有一条主线**（90 分钟完整流程），辅线最多做 20 分钟轻量输入（读一节书/复习旧笔记）
- 一天内三线全做完整流程 = 每条线都停在 L1，是最差策略

### 利用内容呼应做交错（Interleaving）

| AI Agent 书 | 对应课程 | 建议时机 |
| --- | --- | --- |
| 第 2 章 上下文工程 | CS224n Transformers（视频 8） | 学完 Transformer 后读，互相印证 |
| 第 3 章 记忆与 RAG | CS224n Agents/RAG（slides 10） | 一起看 |
| 第 4 章 工具/MCP | CS224n Agents/RAG（slides 10） | 一起看 |
| 第 6 章 Agent 评估 | CS224n Benchmarking（视频 12 / slides 11） | 一起看 |
| 第 7 章 模型后训练 | CS224n Post-training（视频 11）+ CS336 assignment5 | 三者汇合点 |
| 第 1、5、8、9、10 章 | 无直接对应 | 作为调剂，插在主线疲劳时 |

**呼应点的核对方式升级**：同一个概念（如 RLHF）在书里读过又在课里听过之后，L2 检验变成——"合上讲义，写出这两个来源各自怎么讲、侧重点差在哪"。能写出差异 = 真懂。

### 每周节奏模板

```
周一/三/五   CS224n 主线（1 个视频 + 对应 slides + 白纸笔记）
周二/四      作业主线（a1→a4 顺序做，卡壳超过 2 小时才看提示不看答案）
周六         AI Agent 书主线（1 章 + 挑 2-3 个实验跑通）
周日         复习日：不做新内容
             - 把本周所有笔记的 ❌ 缺口重测一遍
             - 到期的 review 日期清掉
             - 更新所有进度表
```

## 五、笔记规范

### 文件命名

- CS224n：`courses/cs224n/notes/lec01-word-vectors.md`
- CS336：`courses/cs336/notes/lec01-tokenization.md`
- AI Agent 书：`books/notes/ai-agent-book/ch01-basics.md`

### 笔记模板

```markdown
# <标题>
review: D+1 2026-xx-xx / D+7 2026-xx-xx / D+30 2026-xx-xx
source: <视频链接或章节路径>

## 白纸默写区（先写，后对照）
<关材料写的内容>

## 缺口与纠正
- ❌ <漏掉/记错的点> → 正确是：<...>

## 为什么（L2 因果链）
- <概念>：为什么这样设计？<自己的解释>

## 动手验证（L4）
- 作业/实验：<做了什么，测试结果>

## 收尾三行
- 卡在哪：
- 为什么卡：
- 下次怎么想起来：
```

### 两条铁律

1. **先默写后对照**，顺序不能反——边看边抄的笔记没有诊断价值
2. 笔记里**必须有 ❌**，一篇没有缺口的笔记说明你没真测（或这讲太简单，可以加速跳过）

## 六、防自欺检查清单

出现以下信号，说明在"假学习"，回到 ② 白纸输出重测：

- 看视频时频频点头，但合上视频说不出三个要点
- 笔记内容 80% 以上是复制/截图
- 作业"看懂了答案"就算做完
- 进度表 ✅ 增加很快，但两周前的内容已经讲不出来
- 同一处缺口在复习时第二次 ❌
