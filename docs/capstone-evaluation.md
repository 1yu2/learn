# 个人研究 Agent 项目方向与完成度评估

## 方向选择

| 方向 | 学习覆盖 | 数据复杂度 | 安全风险 | 演示价值 |
| --- | --- | --- | --- | --- |
| 本地资料研究助手 | Plan、只读工具、RAG、结构化输出、Event、权限 | 中 | 中 | 高 |
| 知识库问答助手 | RAG、引用、记忆、服务化 | 中高 | 中 | 高 |
| 代码仓库讲解助手 | 文件工具、Plan、权限、事件流 | 高 | 高 | 高 |

推荐先做“本地资料研究助手”：它覆盖当前仓库的关键框架能力，输入数据可控，能在不开放写权限的前提下完成完整演示。完成 MVP 后再把同一套边界扩展到知识库或代码仓库。

## MVP 范围

用户输入一个研究主题，Agent 完成以下流程：

1. 创建结构化研究计划，并展示任务状态。
2. 只读访问白名单目录中的 Markdown/TXT 资料。
3. 对资料建立本地索引并完成 RAG 检索。
4. 输出带来源片段的结构化研究摘要。
5. 通过事件流展示模型调用、检索和任务进度。
6. 对写文件、命令执行等高风险操作默认拒绝或要求确认。
7. 提供无 API key 的单元测试和一个需要真实 provider 的手工演示命令。

## 里程碑与退出条件

| 里程碑 | 交付物 | 退出条件 |
| --- | --- | --- |
| M1 配置与边界 | Settings、prompt、安全约束 | 无 key 可运行测试，越界路径被拒绝 |
| M2 工具与计划 | 只读工具、Plan 状态 | 任务至少经历创建、执行、完成，拒绝写操作 |
| M3 检索与摘要 | 本地知识库、RAG、结构化 schema | 预置问题能召回正确片段，摘要包含来源 |
| M4 事件与测试 | 事件展示、离线测试、故障记录 | 能解释一次失败，测试覆盖关键边界 |
| M5 演示与复盘 | README、截图/日志、评分表 | 新环境按文档可复现，风险清单已关闭或记录 |

## 必测风险

- **幻觉引用**：摘要不得声称资料中不存在的来源；没有召回证据时明确标注未知。
- **未授权写入**：默认只读；对写入和命令执行使用权限决策，并有拒绝测试。
- **session 串扰**：两个 session 的任务、workspace 和记忆不能互相读取。
- **工具错误隐身**：工具异常必须进入事件/日志，不能伪装成正常答案。
- **超长上下文**：资料过长时触发压缩或截断策略，并保留关键约束。

## 100 分评分表

| 维度 | 分值 | 达标证据 |
| --- | ---: | --- |
| 功能完成度 | 35 | 主题输入、Plan、只读资料、RAG、结构化摘要、事件流均可演示 |
| AgentScope 概念覆盖 | 20 | 至少使用 Agent、Toolkit/Tool、Event、Plan、Context 或 Middleware、RAG |
| 测试与可靠性 | 20 | 离线单元测试、错误路径测试、一次真实 provider 集成验证和故障记录 |
| 安全与权限 | 15 | 路径白名单、工具权限、确认/拒绝路径、key 脱敏、session 隔离说明 |
| 可观测性与文档 | 10 | 运行命令、架构图或数据流、事件日志、限制和排错文档 |

评分结论：`90-100` 为完成；`75-89` 为可用 beta；`60-74` 为学习原型；低于 `60` 为未完成。无论总分多少，若存在真实 key 泄露、默认可写越权或 session 数据串扰，项目不得判为完成。
